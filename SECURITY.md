# Security

Report a vulnerability in this package or in the AY Inbox API by email to team@ayinbox.com. Please do not open a public issue for it.

Include what you found, how to reproduce it and which version you used. We will answer and keep you informed while we fix it.

Never paste a real API key or OAuth token into an issue, a pull request or a log. If a key was exposed, revoke it in the AY Inbox dashboard and create a new one.
